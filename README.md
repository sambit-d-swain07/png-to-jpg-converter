# PNG to JPG Converter 🔄🖼️

An elegant and easy-to-use web app to convert PNG images to JPG instantly. Built using pure HTML, CSS, and JavaScript — no backend required, all client-side!

---

## 🚀 Features

- ✅ Convert PNG to JPG in your browser
- ✅ No registration required
- ✅ Drag & Drop file support
- ✅ Batch conversion
- ✅ 100% privacy — files never leave your device

---

## 🔧 Usage

1. Clone or download this repo
2. Open `index.html` in your browser
3. Drag and drop your `.png` images or click to upload
4. Click **Convert All to JPG** to start conversion
5. Download your converted images
